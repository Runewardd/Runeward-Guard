# Build path

Guard is intentionally separate from Runeward's container control plane. The first version should earn trust as an endpoint product before any central fleet features are added.

1. **Local decision core (implemented foundation).** Deterministic secret heuristics, screenshot correlation, no raw-content findings, tests, and a synchronous check command. The original example feed remains synthetic.
2. **Trusted harness adapters (Claude Code, Codex, and Copilot CLI hooks started).** Add one integration at a time for prompt checks and tool-use metadata. Copilot CLI's command hook can replace transformed model-facing text but cannot block the original submitted prompt; its tool hook can deny selected commands. Live harness validation and other Copilot surfaces remain. A hook is not equivalent to observing all chats or all network sends.
3. **macOS endpoint sensor (unsigned testable core).** The process-graph correlation engine, replay fixture, and Endpoint Security callback code exist. A signed app/system-extension bundle, Apple entitlement, device approval, Full Disk Access, and live integration testing remain. Direct Keychain-file opens can be correlated without reading item values; Security.framework-mediated accesses are not attributable to a harness yet. Add operator pause and clear sensor-health reporting.
4. **Disclosure correlation (partial).** Chrome selection and clipboard image paste are observed. Exact selected-image bytes in a same-origin raw HTTP request body plus 2xx completion produce a stronger finding. Multipart, transformed, third-party, WebSocket, other-browser, and desktop-app transfers remain uncovered. Never describe unobserved channels as protected.
5. **Management plane (local operations started).** The unprivileged monitor has private daily audit files with retention, a read-only doctor command, and an opt-in user LaunchAgent setup. Next add a signed system-extension deployment, durable health alerts, signed updates, device enrollment, signed policy distribution, minimal finding ingestion, and a Runeward cross-link. Keep raw prompts and screenshots on-device by default. Define role-based access before enabling remote findings.
6. **Retrospective review (Guard logs only).** The bounded `audit-summary` command reports finding counts from an operator-selected Guard log. It cannot reconstruct earlier unseen activity. Broader historical sources require explicit opt-in, source-specific confidence labels, and deletion controls; browser history alone cannot recover prompt content.

Before shipping an EDR claim, add tamper resistance, signed updates, uninstall/recovery flow, enrollment, performance budgets, cross-user testing, security review, and a documented coverage matrix for each supported harness and OS version.
